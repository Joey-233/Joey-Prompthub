FEATURES · 06
01

悬浮球入口

常驻桌面最上层，单击展菜单，双击直达主面板，长按拖到任意位置。不抢镜，但始终待命。

02

快速收录

迷你输入框 / 剪贴板一键导入，标题自动取前 20 字符。Ctrl+Enter 立刻入库，灵感永不流失。

03

分类与标签

绘图 / LLM 双类型，逗号分隔的自定义标签，关键词搜索，井井有条。

04

AI 优化

一键调用 Claude / OpenAI，增强细节、精简表达或自定义指令，原文与优化版并列对比采纳。

05

出图测试台

直连 Stable Diffusion WebUI / DALL·E 3，临时修改不动原文，多图并排对比，满意再存回。

06

本地优先

SQLite 本地数据库，API Key 经 Electron safeStorage 加密。JSON 导入导出，资产完全自有。

01

记下灵感

看到好提示词复制；单击悬浮球，「粘贴板导入」。悬浮球闪烁——保存成功。

02

整理与优化

双击悬浮球打开主面板。打标签、加备注，或交给 AI 优化按钮润色。

03

边试边改

切换到测试台，调参数、出图、对比，满意的版本一键存回提示词库。

常见问题

FAQ
完全免费吗？+

是的，Prompt Hub 完全免费、开源，没有任何内购或付费功能。MIT 协议允许商业使用。

我的提示词存在哪里？会上传云端吗？+

全部存在本地 SQLite 数据库，不会上传任何服务器。可在设置中查看数据库路径，并随时导出 JSON 备份。

API Key 安全吗？+

使用 Electron 提供的 safeStorage 加密存储，只能在你的当前用户账户下解密读取。

支持哪些出图服务？+

当前支持 Stable Diffusion WebUI 与 OpenAI DALL·E 3，后续将通过自定义 provider 接入更多服务。
