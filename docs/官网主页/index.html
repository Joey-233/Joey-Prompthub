FEATURES · 06
01

悬浮球入口

常驻桌面最上层，单击展菜单，双击直达主面板，长按拖到任意位置。不抢镜，但始终待命。

02

快速收录

主面板输入框 / 剪贴板一键导入，Ctrl+Enter 立刻入库，灵感永不流失。

03

分类与标签

绘图 / LLM 双类型，逗号分隔的自定义标签，关键词搜索，井井有条。

04

AI 优化

通过豆包、DeepSeek 或自定义 OpenAI 兼容接口，增强细节、精简表达或执行自定义优化指令。

05

Seedance 2 模板

内置七分区“默认模板1”，自由组织角色与素材锚定、镜头序列、台词和风格，也可自定义默认模板。

06

本地优先

SQLite 本地数据库，API Key 经 Electron safeStorage 加密；无法安全加密时拒绝明文保存。

01

记下灵感

看到好提示词复制；单击悬浮球，选择「收录剪贴板文本」，内容立即入库。

02

整理与优化

双击悬浮球打开主面板。打标签、加备注，或交给 AI 优化按钮润色。

03

编排成片提示

进入 Seedance 2，组织参考素材与镜头序列，实时预览并复制完整提示词。

常见问题

FAQ
完全免费吗？+

是的，Joey Prompthub 完全免费、开源，没有任何内购或付费功能。MIT 协议允许商业使用。

我的提示词存在哪里？会上传云端吗？+

提示词和模板默认保存在本地 SQLite 数据库。只有你主动使用 AI 优化或识图时，相关内容才会发送到你选择的服务商。

API Key 安全吗？+

使用 Electron 提供的 safeStorage 加密存储，只能在你的当前用户账户下解密读取。

支持哪些文字 API？+

内置豆包和 DeepSeek 官方地址，也可以填写任意 OpenAI Chat Completions 兼容地址、模型和自己的 API Key。
