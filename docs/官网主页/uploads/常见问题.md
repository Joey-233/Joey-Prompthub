
# 常见问题

## 安装与启动

### Q: 支持哪些操作系统？
A: Windows 10+、macOS 11+，以及主流 Linux 发行版（Ubuntu、Fedora、Debian 等）。

### Q: 安装失败怎么办？
A: 请确保你的系统满足最低要求，并关闭杀毒软件后重试。如仍有问题，请在 GitHub 提交 Issue。

### Q: 悬浮球不显示？
A: 请尝试右键任务栏托盘图标，选择「显示悬浮球」。如仍不显示，请重启应用。

---

## 数据与隐私

### Q: 我的数据存在哪里？
A: 全部存在本地 SQLite 数据库中，不会上传任何服务器。你可以在设置中查看数据库路径。

### Q: 如何备份我的提示词库？
A: 在设置 → 数据管理中，点击「导出 JSON」，选择保存位置即可。

### Q: API Key 安全吗？
A: API Key 使用 Electron 提供的 safeStorage 加密存储，只有在你的当前用户账户下才能解密。

## 功能使用

### Q: 支持哪些出图服务？
A: 当前支持 Stable Diffusion WebUI 和 OpenAI DALL·E 3，未来会添加更多服务。

### Q: AI 优化功能怎么用？
A: 在提示词编辑面板点击「AI 优化」按钮，选择优化方向（增强细节/精简/自定义），点击生成后对比采纳。

### Q: 悬浮球可以隐藏吗？
A: 可以。在设置中关闭「显示悬浮球」，此时应用会退至托盘运行，通过托盘图标可以重新显示悬浮球或打开主面板。

### Q: 能同时运行多个 Prompt Hub 吗？
A: 不能，应用设计为单例运行，第二个实例启动时会自动唤醒已在运行的实例。
