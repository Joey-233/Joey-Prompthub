
# 功能特性

## 核心功能

### 1. 悬浮球 - 灵感随时收录

- **常驻桌面** - 始终在屏幕最上层，不抢焦点
- **快捷菜单** - 单击展开，包含快速录入、粘贴板导入、打开主面板、设置
- **迷你录入** - 点击「快速录入」，悬浮球变身为迷你输入面板，敲完即存，自动缩回
- **粘贴板导入** - 一键读取剪贴板文本，直接存入，存完悬浮球会闪烁给你反馈
- **双击直达** - 双击悬浮球快速打开主面板
- **自由拖拽** - 长按即可移动悬浮球到任意位置

### 2. 提示词库 - 有序管理

- **双类型支持** - 绘图提示词 / LLM 提示词分类管理
- **卡片网格** - 每张卡片显示标题、类型标签、内容预览、标签
- **快速录入栏** - 主面板顶部固定输入框，粘贴即存，标题自动取前 20 字符
- **高级筛选** - 支持按类型筛选（全部/绘图/LLM）+ 关键词搜索
- **标签系统** - 用逗号分隔的标签，自定义分类维度
- **编辑面板** - 点击卡片滑出编辑侧边栏，修改自动保存（防抖 1 秒）
- **AI 优化** - 一键调用 Claude 或 OpenAI，优化提示词质量
- **一键复制** - 快速把提示词复制到剪贴板

### 3. 测试台 - 边试边改

- **选词加载** - 左侧只列绘图类型提示词，点选即加载到右侧
- **临时编辑** - 在测试台中修改不影响库中原文，满意再存回
- **参数配置** - 服务选择、尺寸、步数、采样器等完整参数调节
- **生成历史** - 记录每次生成的图片和参数，支持并排对比
- **结果网格** - 多图网格布局，直观查看效果差异

### 4. AI 优化 - 让提示词更专业

- **多种优化方向** - 增强细节 / 精简表达 / 自定义指令
- **智能建议** - 基于 Claude / OpenAI 模型给出专业建议
- **对比采纳** - 并列显示原文和优化版，决定是否替换

### 5. 数据管理 - 完全掌控

- **本地 SQLite** - 数据全部存在本地，不上传任何服务器
- **JSON 导入导出** - 轻松备份、迁移、分享你的提示词库
- **安全存储** - API Key 使用 Electron safeStorage 加密保存

---

## 小而美细节

- **深色/浅色主题** - 支持跟随系统或手动切换
- **开机自启** - 悬浮球随系统启动，不用每次手动打开
- **系统托盘** - 除了悬浮球，额外提供托盘图标作为备用入口
- **平滑动画** - 窗口切换、菜单展开、面板滑动都有舒适的过渡
- **全中文界面** - 友好的中文操作体验
