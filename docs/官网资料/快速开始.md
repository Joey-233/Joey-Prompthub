
# 快速开始

## 安装

### 系统要求

- Windows 10+ / macOS 11+ / Linux (主流发行版)
- 至少 100MB 可用磁盘空间

### 下载安装

&gt; 下载链接即将上线...

下载后直接运行安装程序，按提示操作即可。

---

## 初次启动

### 1. 欢迎界面

首次启动会看到快速入门指南，点击「开始使用」进入主界面。

### 2. 配置悬浮球

悬浮球会默认出现在屏幕右侧中间位置：

- 单击 → 展开菜单
- 双击 → 打开主面板
- 长按拖拽 → 移动位置

### 3. 基础设置

右键悬浮球或在主面板打开「设置」：

- 配置 AI 服务（API Key）- 用于提示词优化
- 配置出图服务 - 用于测试台生成图片
- 选择主题（深色/浅色/跟随系统）
- 设置是否开机自启

---

## 快速入门

### 场景一：快速记录灵感

1. 看到好的提示词，全选复制
2. 单击悬浮球，点「粘贴板导入」
3. 悬浮球闪烁 = 保存成功！
4. 完事，继续你的工作

### 场景二：管理你的提示词库

1. 双击悬浮球打开主面板
2. 在顶部快速录入栏粘贴或输入
3. 选择类型（绘图/LLM），回车即存
4. 点击卡片可以编辑详情、添加标签
5. 不满意的话，点击「AI 优化」让 AI 帮你润色

### 场景三：测试绘图提示词

1. 打开「测试台」视图
2. 左侧选择一个绘图提示词
3. 右侧调整参数（尺寸、步数等）
4. 点击「生成」查看效果
5. 满意的话，点「存回提示词库」

## 键盘快捷键

| 操作 | 快捷键 |
|------|--------|
| 打开主面板 | 双击悬浮球（或配置全局快捷键） |
| 快速录入 | 悬浮球菜单 → 快速录入 |
| 复制提示词 | 在编辑面板点击「复制」 |
