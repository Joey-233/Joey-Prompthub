
# 快速开始

## 安装

### 系统要求

- Windows 10+
- 至少 100MB 可用磁盘空间

### 下载安装

&gt; 下载链接即将上线...

下载后直接运行安装程序，按提示操作即可。

---

## 初次启动

### 1. 配置悬浮球

悬浮球会默认出现在屏幕右侧中间位置：

- 单击 → 展开菜单
- 双击 → 打开主面板
- 长按拖拽 → 移动位置

### 2. 基础设置

右键悬浮球或在主面板打开「设置」：

- 选择豆包、DeepSeek 或自定义 OpenAI 兼容服务
- 填写 Base URL、模型与自己的 API Key
- 检查文字 API 连接

---

## 快速入门

### 场景一：快速记录灵感

1. 看到好的提示词，全选复制
2. 单击悬浮球，点「粘贴板导入」
3. 悬浮球闪烁 = 保存成功！
4. 完事，继续你的工作

### 场景二：管理你的提示词库

1. 双击悬浮球打开主面板
2. 在顶部快速录入栏粘贴或输入
3. 选择类型（绘图/LLM），回车即存
4. 点击卡片可以编辑详情、添加标签
5. 不满意的话，点击「AI 优化」让 AI 帮你润色

### 场景三：编辑 Seedance 2 分镜模板

1. 打开「Seedance2」视图
2. 新建模板或选择已有模板
3. 编辑角色与素材锚定、镜头序列和台词
4. 在右侧实时预览完整提示词
5. 保存模板，必要时设为默认并复制使用

## 键盘快捷键

| 操作 | 快捷键 |
|------|--------|
| 打开主面板 | 双击悬浮球（或配置全局快捷键） |
| 快速录入 | 悬浮球菜单 → 快速录入 |
| 复制提示词 | 在编辑面板点击「复制」 |
