
# 技术栈

Prompt Hub 是一个现代化的跨平台桌面应用，采用以下技术构建：

---

## 基础架构

| 层次 | 技术选型 | 说明 |
|------|----------|------|
| 应用壳 | Electron | 跨平台桌面应用框架，Chromium + Node.js |
| 构建工具 | electron-vite | 为 Electron 优化的 Vite 构建方案 |
| 语言 | TypeScript | 类型安全的 JavaScript 超集 |
| UI 框架 | React 19 | 组件化前端框架 |
| 样式 | Tailwind CSS 4 | 原子化 CSS 框架 |
| 状态管理 | Zustand | 轻量级、高性能状态管理 |
| 数据库 | better-sqlite3 | Node.js 最快的 SQLite 驱动 |

## 架构设计

### 双窗口架构

```
悬浮球窗口 (BrowserWindow)
  - frame: false, transparent: true
  - alwaysOnTop: true
  - skipTaskbar: true

主面板窗口 (BrowserWindow)
  - 常规应用窗口
  - 关闭时仅隐藏，不退出

两个窗口共享同一个主进程与 SQLite 数据库
```

### 数据模型

#### Prompts 表
```
id          TEXT PRIMARY KEY
title       TEXT NOT NULL
content     TEXT NOT NULL
tags        TEXT JSON DEFAULT '[]'
params      TEXT JSON DEFAULT '{}'
created_at  TEXT DEFAULT (datetime('now'))
updated_at  TEXT DEFAULT (datetime('now'))
```

#### Generations 表
```
id          TEXT PRIMARY KEY
prompt_id   TEXT REFERENCES prompts(id)
image_data  TEXT NOT NULL
params      TEXT JSON DEFAULT '{}'
created_at  TEXT DEFAULT (datetime('now'))
```

### IPC Bridge

```typescript
interface Prompt HubAPI {
  prompts: {
    list(filter?: { type?: string; search?: string }): Prompt[];
    create(content: string, type: 'image' | 'llm'): Prompt;
    update(id: string, patch: Partial&lt;Prompt&gt;): Prompt;
    delete(id: string): void;
  };
  ai: {
    optimize(content: string, direction: string): Promise&lt;string&gt;;
  };
  generate: {
    run(prompt: string, negative: string, params: GenParams): Promise&lt;string&gt;;
    providers(): string[];
  };
  system: {
    clipboardImport(): Promise&lt;Prompt | null&gt;;
    toggleMainWindow(): void;
  };
}
```
