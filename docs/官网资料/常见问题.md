
# 常见问题

## 安装与启动

### Q: 支持哪些操作系统？
A: 当前正式支持 Windows 10 及更高版本。

### Q: 安装失败怎么办？
A: 请确保你的系统满足最低要求，并关闭杀毒软件后重试。如仍有问题，请在 GitHub 提交 Issue。

### Q: 悬浮球不显示？
A: 请尝试右键任务栏托盘图标，选择「显示悬浮球」。如仍不显示，请重启应用。

---

## 数据与隐私

### Q: 我的数据存在哪里？
A: 提示词和模板存在 `%APPDATA%\Prompt Hub` 下的本地 SQLite 数据库中。只有主动使用 AI 优化或识图时，相关内容才会发送到你选择的服务商。

### Q: 如何备份我的提示词库？
A: 退出应用后备份整个 `%APPDATA%\Prompt Hub` 目录。API Key 受当前 Windows 用户凭据保护。

### Q: API Key 安全吗？
A: API Key 使用 Electron 提供的 safeStorage 加密存储，只有在你的当前用户账户下才能解密。

---

## 功能使用

### Q: 支持哪些文字 API？
A: 内置豆包和 DeepSeek 官方地址，也支持任意 OpenAI Chat Completions 兼容地址。

### Q: AI 优化功能怎么用？
A: 在提示词编辑面板点击「AI 优化」按钮，选择优化方向（增强细节/精简/自定义），点击生成后对比采纳。

### Q: 悬浮球可以隐藏吗？
A: 可以。在设置中关闭「显示悬浮球」，此时应用会退至托盘运行，通过托盘图标可以重新显示悬浮球或打开主面板。

### Q: 能同时运行多个 Joey Prompthub 吗？
A: 不能，应用设计为单例运行，第二个实例启动时会自动唤醒已在运行的实例。
